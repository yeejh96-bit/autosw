# Codex 설치·첫 사용 안내

처음 설치할 때는 [README의 빠른 설치](../README.md#빠른-설치)에서 **Node 설치 한 줄 → PowerShell·Codex 재시작 → autosw 설치 한 줄** 순서로 진행합니다. 기존에 공유한 이 주소도 계속 사용할 수 있습니다.

1. [빠른 설치](../README.md#빠른-설치)를 따릅니다. 다른 설치 경로가 필요하면 [설치 방법 선택](../README.md#설치-방법-선택)을 확인합니다.
2. [MCP 설치](../README.md#mcp-설치-권장)와 [GitHub 플러그인 설치](../README.md#github-플러그인-설치) 중 하나만 선택합니다.
3. 개인 작업 폴더를 Codex에서 열고 [첫 사용 요청문](../README.md#설치-후-첫-사용)으로 실제 연결을 확인합니다.

다른 위치에 설치하거나 소스 ZIP을 받았을 때, 기존 설치를 업데이트·제거할 때, 명령행이나 다른 MCP 앱을 사용할 때의 안내도 README에 있습니다. npm·GitHub 가입이나 게시자용 보안키는 필요하지 않습니다.
