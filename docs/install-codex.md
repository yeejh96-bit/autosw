# Codex 설치·첫 사용 안내

1. [README의 빠른 설치](../README.md#빠른-설치)에 있는 PowerShell 두 줄로 GitHub 카탈로그와 autosw 플러그인을 추가합니다.
2. Codex 앱을 다시 열고 플러그인 설정을 실행합니다. 설정 버튼이 없으면 새 대화에서 “autosw 처음 설정해줘”라고 요청합니다.
3. 처음 설정에서 필요한 실행 환경과 바탕화면 업무 폴더를 준비합니다. 기존 autosw 업무 폴더가 있으면 그 위치를 지정할 수 있습니다.
4. 설치가 알려 준 업무 폴더를 Codex 프로젝트로 열고 새 대화에서 문서 작업을 시작합니다.

프로젝트의 양식·장부는 플러그인과 별도입니다. 폴더를 통째로 옮겼다면 새 위치를 Codex에서 엽니다.
