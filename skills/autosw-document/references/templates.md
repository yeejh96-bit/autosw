# 양식 고르기와 활동 차이

초안의 항목을 정하거나 한글 양식을 고를 때 읽는다. 양식은 사용자가 지정한 파일이나 작업 폴더의 `templates/`에서 찾고, 그 밖의 폴더를 스스로 탐색하지 않는다.

## 선택 순서

1. 사용자가 이번에 지정한 양식을 쓴다.
2. 같은 세부활동·같은 문서 종류의 확인된 최신 선례를 쓴다. 특정 행사 유형의 전용 양식이 있으면 다른 활동의 선례보다 먼저 쓴다.
3. 항목 순서와 표 구성이 가장 가까운 양식을 고른다. 사업명만으로 양식을 고정하지 않는다.
4. 맞는 양식이 없으면 [문서 종류 선택표](types.md)의 기준으로 내용 초안을 작성한다.

계획서와 결과보고서는 각각 고른다. 다른 활동의 선례는 맞는 선례가 없을 때 구조·표현 참고로만 쓴다.

## 양식 속 과거 내용

실제로 쓴 지난 문서를 양식으로 쓰는 경우가 많으므로 빈 양식으로 간주하지 않는다. 행사명·날짜·인원·금액·강사·평가·서명·사진과 대괄호 안내문은 이번 문서의 사실이 아니다. 양식의 비교 행이나 사진 칸 수가 견적 확보나 사진 존재를 뜻하지 않는다.

## 활동 차이 반영

- 시간표의 열이 같고 내용만 다르면 같은 양식을 쓴다. 분반별 시간 열처럼 구조가 다를 때만 해당 구조의 양식을 고르고, 분반 수가 다르면 작업 사본에서 표를 조정한 뒤 다시 검증한다.
- 분반 결과는 전체 인원과 분반별 인원을 대조하고 분반 간 차이와 공통 관찰을 구분한다.
- 자조모임처럼 논의가 중심이면 확인된 안건·진행·합의 내용을 수행과 총평에 나눈다. 빈 예산표를 채우려고 지출을 만들지 않는다.
- 교육·특강은 주제·소주제·실제 진행 흐름을, 제작·체험은 단계·준비물·과정의 관찰을 담는다.
- 번호형 문서는 같은 종류의 선례에서 목적·개요·세부내용·예산·기대효과 또는 평가의 순서를 확인한다. 필요 없는 전체 사업용 절을 남기거나 한 회기 시간표에 억지로 줄이지 않는다.
- 물품 구입은 견적금액과 실제 지출을 구분한다. 비교업체·부가세 포함 여부·선정 여부·예산은 확인된 근거만 쓴다.

## 양식이 없어도 되는 문서

회의록·소식지 기사·홍보글처럼 글을 받아 사용자가 직접 붙여 넣는 문서는 본문만 제시한다. 한글 양식을 찾거나 요구하지 않는다. 평가서·연간보고·외부 제출 서식처럼 표 배치가 꼭 필요한데 양식이 없으면 내용 초안을 먼저 쓰고, 해당 파일을 지정해 달라고 한 줄로 요청한다.

## 붙여 넣기용 본문

한글 양식에 옮길 본문을 대화로 줄 때는 실제 양식에서 확인한 표의 행·열·병합 칸 순서에 맞추고 항목명을 붙인다. 한 칸에 들어갈 내용은 묶는다. 변환 글의 순서만으로 칸 위치를 정하지 않는다. 구조를 확인하지 못했으면 문서의 항목 순서를 따르고 칸 구조를 추측하지 않는다. 파일 작성을 요청받지 않았으면 한글파일을 만들지 않는다.

## 입력과 완료

선택한 파일·채울 항목·사실 근거·빠진 값을 정한 뒤 [한글 출력](hangul.md)으로 이어간다. 양식을 한 번 검증했어도 실제 작성본의 길이·표·사진 배치는 다시 확인한다. 본문과 표의 날짜·인원·금액이 다르면 한 값을 임의로 고르지 않고 대조 필요로 남긴다.
