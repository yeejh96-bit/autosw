# 결과와 평가

## 회기 결과보고서

실제 수행내용·수행인력·인원·예산·평가를 확인된 양식에 대응한다. 총평은 진행 개요, 활동별 과정, 담당자 관찰·개입, 참여자 반응, 향후 방향을 근거에 맞춰 연결한다. 참여자 발언·연락·준비·마무리 행동은 이번 회기에 확인된 경우만 쓴다. 계획과 달라진 사항은 확인된 사유와 함께 설명한다. 출석 변화를 비교하려면 양쪽 인원과 집계 범위가 확인돼야 한다.

## 행사·오리엔테이션·개강식 결과

개요, 사전준비와 실제 진행, 역할, 예산, 평가, 사진 등 지정 항목을 따른다. 후원·협력기관과 제공 내용은 실제 확인된 범위만 적는다. 문제점과 개선방안은 서로 대응시키고 참여자 소개·규칙 합의·자료 배부 등은 실제 진행한 경우만 기록한다. 행사 단계의 이름만 반복하지 말고 평가 근거가 있는 내용을 설명한다.

## 모집 결과보고서

실제 기간과 경로, 신청·선정·참여 인원, 목표 대비 결과를 구분한다. 경로별 실적은 해당 집계가 있을 때만 나눈다. 미달·초과 원인과 후속 모집은 확인된 사실 또는 제안임을 표시한다.

## 연간결과보고서·반기 평가서

목표, 투입과 과정, 산출과 성과, 예산, 피드백 반영, 총평과 다음 기간 계획을 실제 양식에 맞춘다. 기간별 목표·실적·누계를 구분하고 연간 목표를 임의로 반기 값으로 나누지 않는다. 투입 인원과 실제 참여, 활동량과 효과를 구분한다. 사전·사후 척도와 관찰 자료가 있으면 대상·측정 시점·척도의 일치 여부를 확인한 뒤 설명한다.

## 최종평가회 결과

평가회 행사의 진행 결과와 사업 전체의 성과 평가를 구분한다. 척도·만족도 조사 결과를 넣으면 조사 대상·시점·도구·응답 범위·실제 값을 확인한다. 변화량과 비율은 계산하고 표본의 한계를 밝힌다. 수료식·검사·피드백 중 실제 수행하지 않은 항목을 관행으로 추가하지 않는다.
