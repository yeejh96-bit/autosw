# 문서 종류 선택표

현재 문서에 해당하는 참조만 읽는다. 아래 분류는 작성 지침의 범위이며 모든 양식의 자동 편집을 보장하지 않는다. 한글 출력 지원 여부는 실제 파일 구조와 검증 결과로 판단한다.

| 종류 | 참조 |
|---|---|
| 사업·회기·홍보·모집 계획서, 외부 공모·후원 제안서 | [계획과 제안](planning.md) |
| 회기·행사·모집 결과, 연간·반기 평가, 평가회·오리엔테이션 결과 | [결과와 평가](results.md) |
| 내부 회의록, 간담회, 정기회의·자조모임 보고 | [회의와 논의](meetings.md) |
| 복명서, 설문지, 조사 결과, 소식지·홍보글·칼럼, 기안 붙임, 공적조서 | [기타 문서](other-documents.md) |

종류가 목록에 없어도 목적과 지정 양식이 확인되면 그 구조에 맞춰 초안을 작성한다. 확인되지 않은 기관 관행이나 제출 규정을 새로 만들지 않는다.
