# 양식 입력 JSON

기존 HWPX 양식에 승인된 본문을 넣는 `fill` 미리보기를 준비할 때 읽는다. 먼저 `inspect`로 사용할 파일을 읽는다. 요청 JSON은 UTF-8로 `drafts/`에 새 파일로 저장한다. `preview --kind fill`의 `--request`에 저장한 JSON 경로를 지정한다.

## 최상위 필드

| 필드 | 형식 | 작성 방법 |
|---|---|---|
| `schemaVersion` | 정수 | 현재 값은 `1` |
| `sourceSha256` | 문자열 | 이번 `inspect`가 반환한 `sourceSha256`를 그대로 사용 |
| `changes` | 변경 객체 배열 | 최소 한 항목. 아래 변경 필드에 따라 실제 대상을 지정 |
| `requiredTargets` | 문자열 배열 | 필수 작성 위치의 `targets[].key`. 나열한 대상은 `changes`에 조치가 있어야 함 |
| `unmapped` | 빈 배열 | 대응하지 못한 항목이 없어야 `[]`로 확정. 미대응 내용이 있으면 요청 작성부터 보완 |

엔진은 `requiredTargets`와 `unmapped`의 생략을 허용하지만, AI는 필수 입력 누락을 확인할 수 있도록 두 필드를 작성한다. 정의되지 않은 추가 필드는 거부된다. 원본이 바뀌면 새 `inspect` 결과로 대응과 미리보기를 다시 만든다.

## 변경 객체 필드

| 필드 | 형식 | 작성 방법 |
|---|---|---|
| `target` | 문자열 | `inspect`의 `targets[].key`를 그대로 사용. 파일명·항목명으로 위치 키를 추측하지 않음 |
| `label` | 비어 있지 않은 문자열 | 사용자에게 보여 줄 실제 항목명 |
| `source` | 비어 있지 않은 문자열 | 입력값 또는 비우기·보존 판단의 확인된 근거. 출처 설명이며 파일을 자동으로 읽는 경로가 아님 |
| `action` | 문자열 | `set`, `clear`, `preserve` 중 하나 |
| `expected` | 문자열 배열 | 해당 대상의 `before` 배열을 순서·공백·줄바꿈까지 그대로 복사 |
| `values` | 문자열 배열 | 기존 문단 수와 같은 개수의 입력값. `preserve`에서는 생략 가능 |

## 조치와 문단 보존

- `set`: 승인된 본문을 넣는다. `values`의 항목 수는 `before`와 같아야 하며 각 항목이 기존 문단 하나에 대응한다. 전체 항목을 빈 문자열로 만들려면 `clear`를 사용한다.
- `clear`: 명시적으로 비우는 조치다. `values`의 개수는 유지하고 모든 항목을 빈 문자열로 지정한다. 빈칸으로 만들라는 요청이나 승인 범위를 먼저 확인한다.
- `preserve`: 현재 내용을 유지한다. `values`를 생략하거나 `before`와 완전히 같은 배열을 사용한다. 필수 위치를 보존할 때도 보존 사유를 `source`에 기록한다. 필요한 새 내용을 넣지 못했다면 보존 처리만으로 완료했다고 하지 않는다.
- 문단 안 줄바꿈은 LF 문자로 표현한다. JSON 문자열에서는 `\n`을 사용한다. CR·탭·허용되지 않는 XML 문자와 과도하게 긴 값은 거부된다.
- 셀 하나에 여러 문단이 있으면 값을 그 문단 순서에 맞춘다. 문단 수를 늘리거나 줄이는 기능은 이 입력 경로의 범위가 아니다.
- 같은 문단을 두 번 지정하지 않는다. 셀 전체를 지정하면서 그 안의 개별 문단도 함께 지정하면 중복으로 거부된다.

## 수정 가능 여부와 확인

`inspect`의 `writable: true`인 대상만 `set`·`clear`로 변경한다. `writable: false`이면 `reason`을 읽고 보존하거나 작업을 중단한다. 혼합 글자 서식, 보호된 셀, 머리말·꼬리말·제어 요소, 중첩표가 든 부모 셀 등은 변경이 제한될 수 있다. 제한을 해제하거나 해당 내용을 누락시키지 않는다.

미리보기에서 `changes`의 변경 전·후 값과 `unassigned`를 확인한다. `unassigned`는 요청에 지정하지 않은 편집 가능한 영역이며 자동으로 채우거나 비워지는 영역이 아니다. 필수 항목이 남았으면 위치 대응을 보완하고 새 미리보기를 만든다. 모든 입력값과 유지할 내용이 확인되면 [한글 출력](hangul.md)의 승인·생성·검증 단계로 이어간다.
