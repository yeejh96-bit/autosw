# 문서 검토

검토만 요청했을 때 적용한다. 지정한 파일·본문과 사용자가 제공한 근거를 읽고 수정하지 않은 상태로 결과를 제시한다.

- 문서 목적과 지정 양식에 필요한 항목, 사실·수치·날짜·논리의 일관성을 확인한다.
- 합계·단가와 수량의 곱·인원·회차·단위·비율·날짜는 계산 도구로 검산한다. 외부 근거가 없어도 내부 계산은 점검한다.
- 계획과 실제 결과, 목표와 실적, 전체 대상과 응답자, 기간 실적과 누계의 혼용을 확인한다.
- 외부 수치의 진위, 법령·공고·기관 규정의 적용 여부는 확인한 근거 범위만 판단한다. 근거가 없으면 확인 필요로 남긴다.
- 지적마다 원문 위치·문구, 대조 근거, 수정 방향을 붙이고 중대한 사실 오류와 누락을 우선한다. 어느 값이 맞는지 모르면 양쪽 값과 출처를 남긴다.
- 검토 뒤 수정 요청이 오면 그 범위만 반영한다. 파일 수정은 변경 내용을 보여 주고 사용자 승인 범위를 확인한 뒤 수행한다.

장부·일정·외부 데이터베이스를 자동으로 조회하거나 기록하지 않는다. 검토 결과를 특정 개수에 맞추지 않으며 이상이 없는 부분에 문제를 만들지 않는다.
