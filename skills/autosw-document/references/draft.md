# 준비와 초안

새 문서이거나 근거·양식이 달라졌을 때 적용한다. 사용할 자료는 사용자가 제공하거나 접근을 허용한 문서와 설정으로 한정한다.

## 근거와 양식

1. 사업·활동, 문서 종류, 대상 기간, 목적, 핵심 사실과 출처를 파악한다. 초안에 꼭 필요한 빈 정보만 묶어서 묻는다. 사용자가 있는 정보로 작성하라고 하면 미확인 사항을 표시하고 가능한 초안을 만든다.
2. 양식은 사용자 지정 양식, 같은 활동·같은 문서 종류의 확인된 선례, 종류별 기본 기준 순으로 선택한다. 계획서를 결과보고서 양식으로 대신 사용하지 않는다.
3. 참고 자료의 사실 근거와 문체·양식 참고 역할을 구분한다. 과거의 인원·지출·반응·성과·날짜를 이번 실제 사실로 복사하지 않는다.
4. 양식의 전체 항목 순서와 표·병합·빈칸을 확인한다. 평문 추출 결과만으로 표 구조를 확인했다고 하지 않는다. 구조가 확인되지 않으면 내용 초안까지 진행하고 칸 대응은 미확인으로 남긴다.
5. 기관명은 확인한 `autosw.config.json`의 `institution`, 문체 기본값은 `writingPreferences`를 참고한다. 이번 사용자 요청과 지정 양식이 우선하며 실제 수행 사실을 설정값에서 추론하지 않는다. 결재선·직책·직원명은 사용자 입력 또는 확인한 원본을 사용한다. 기관 공통 정보가 없으면 묻거나 비워 둔다.

## 작성

- [공통 문체](style.md)와 [문서 종류 선택표](types.md)의 필요한 기준을 적용한다. 지정 양식의 항목과 이번 요청이 일반 기본형보다 우선한다.
- 확인되지 않은 준비 과정·연락·분위기·발언·개입·효과·후속 조치를 만들지 않는다. 계획, 실제 수행, 관찰, 해석, 제안을 구분한다.
- 사용자 입력과 자료의 숫자가 충돌하면 양쪽 출처와 차이를 알리고 확인이 필요한 값을 남긴다. 문서 내부의 계산은 진행하되 어느 원자료가 사실인지 임의로 정하지 않는다.
- 인용은 실제 확인한 발언과 문구만 사용한다. 이름 표기와 익명화는 문서 목적·기관 기준·사용자 요청에 맞추고 불필요한 식별정보를 반복하지 않는다.
- 예산은 단가·수량·횟수·소계·합계를 대응시킨다. 목표와 실적, 실인원과 연인원, 참석자와 응답자를 구분한다.

## 제시와 수정

초안을 보여 주기 전에 항목 누락, 임의 추가, 수치 불일치, 이전 문서의 사실 잔존을 확인한다. 사실이 비어 있는 항목은 표시하거나 사용자 요청에 따라 자연스럽게 생략하고 그 범위를 본문 밖에 알린다.

초안임을 밝히고 사용한 근거와 미확정 항목을 짧게 제시한다. 수정은 요청한 내용과 영향을 받는 항목만 다시 대조한다. 내용 승인과 한글 출력 요청이 확인되면 [한글 출력](hangul.md)으로 이어간다. 문서 작성만으로 장부·일정·위키·업무일지를 등록하지 않는다.
