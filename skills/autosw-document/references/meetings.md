# 회의와 논의

## 기관 내부 회의록

회의명·일시·장소·참석자와 안건별 배경·논의·결정·담당·기한을 확인된 양식으로 작성한다. 한 항목에는 하나의 판단이나 담당 사항을 담는다. 결정된 내용과 검토 중인 내용을 구분한다. 참석자·직책·장소는 이번 회의 기준으로 확인한다. 녹취의 사담은 제외하고 업무 논의와 결정사항을 요약하되 발언자나 고유명사가 불확실하면 확인 필요로 남긴다.

## 간담회 결과보고서

개요, 준비와 당일 진행, 실행사항과 평가·개선방안, 예산 등 실제 항목을 따른다. 전체 대상 인원, 참석 인원, 설문 응답 인원을 구분하고 서로 다른 집단을 같은 비율의 분모로 사용하지 않는다.

## 정기회의·자조모임 보고서

기관 내부 회의록과 구분하여 실제 계획·수행내용·수행인력·비고와 총평을 지정 양식에 대응한다. 총평에서 논의 배경, 참여자 의견, 결정사항을 연결한다. 담당자가 정한 사항과 참여자가 제안·합의한 사항을 구분한다. 결석자에게 공유한 사실과 후속 조치를 확인 없이 보태지 않는다.
