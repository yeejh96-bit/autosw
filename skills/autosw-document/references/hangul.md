# 한글 출력

승인된 본문을 한글파일로 생성하거나 기존 완성본을 수정하라는 요청에 적용한다. 실제 도구의 도움말과 반환 상태를 읽어 지원 범위를 확인한다. 도구가 지원하지 않는 동작을 임의 명령으로 우회하지 않는다.

## 본문·양식·출력 위치

- 본문 승인과 파일 작성 요청이 확인되면 사용할 본문·양식·출력 위치를 알리고 진행한다. 초안만 요청했다면 출력하지 않는다.
- 지정 양식이 있으면 문단·표·병합·빈칸을 먼저 확인하여 본문을 대응한다. [양식 입력 JSON](form-input.md)을 읽고 `inspect` 결과와 승인 본문으로 요청을 작성한다. 기존 양식을 임의의 새 디자인으로 바꾸지 않는다.
- HWP 입력은 설치된 한글을 통해 작업 사본을 HWPX로 변환하는 경로를 사용한다. `hwp-source-needs-review`이면 원문 내용 자동 대조 미완료로 완성본 저장이 차단된다. 사용자가 HWP 원문과 변환본을 대조한 뒤 변환 HWPX를 새 작성 절차의 입력으로 사용한다. 파일 확장자만 바꾸지 않는다.
- 양식 없는 새 HWPX는 생성기의 지원 항목을 사용한다. 지원하지 않는 그림·서명·혼합 서식·복잡한 표를 누락한 채 완성본이라고 하지 않는다.
- 원본 양식·참고 자료는 보존한다. 최초 결과는 새 파일로 만들고 다른 문서와 이름이 겹치면 새 이름을 정한다.
- 같은 문서의 수정을 요청하면 요청 범위와 기존 완성본 교체를 함께 승인한 것으로 다룬다. 새 후보를 검증한 뒤 도구가 같은 문서로 연결한 기존 대상만 교체한다. 작업 시작 때의 기존 파일과 달라졌으면 최신 내용을 확인한다. 원본 양식·참고 파일·동명 다른 문서에는 이 계속 승인을 적용하지 않는다.

## 미리보기와 생성

1. 입력 본문·양식·출력 경로를 고정한 미리보기를 만든다. 사용자에게 실제 내용과 저장 위치를 제시한다. 이미 승인한 내용과 범위는 다시 승인받지 않는다.
2. 승인 후 변경된 사실·내용·양식·저장 위치가 있으면 영향을 확인하고 새 미리보기를 만든다. 해시나 도구의 확인값은 사용자의 의사 확인을 대신하지 않는다.
3. 미리보기와 일치하는 입력으로 후보 파일을 생성한다. 본문·숫자·대상 밖 내용·표 구조를 대조한다. 미지원 위치와 누락이 있으면 이유를 알리고 중단한다.
4. 일부 단계가 실패하면 기존 파일을 보존하고 성공한 파일·단계와 미완료 단계를 구분한다. 재개 시 완료된 생성·검증을 중복하지 않는다.

## 실제 한글 검증

생성 파일을 한글에서 열고 작업 사본으로 저장·재열기하여 PDF로 출력한다. 검증 도구의 변환 성공만으로 전체 검증 완료라고 하지 않는다. PDF의 모든 페이지에서 글꼴·표·잘림·넘침·빈 페이지·예시 잔존을 확인하고, 한글 재저장본의 사실·숫자·대상 밖 내용과 원문을 다시 대조한다.

자체 미리보기는 근사 조판이며 실제 한글 출력과 구분한다. 파일이나 PDF가 바뀌었으면 이전 미리보기로 확인하지 않는다. 한글 보안 확인이 필요한 경우 사용자에게 허용을 요청하고 대기한다. 보안 설정을 변경하거나 기존 한글 프로세스·문서를 임의로 닫지 않는다.

HWP 납품을 요청받으면 HWPX 후보의 한글 검증에서 형식을 `HWP`로 지정하고 실제 HWP 출력·재열기 뒤 내용 대조용 새 HWPX 사본과 PDF를 만든다. 명령행은 `--format HWP`와 `--verification`을 함께 사용한다. 검증된 HWP와 같은 형식의 새 완성본 경로로 저장한다. 기존 HWP의 원문 대조가 제한된 자동 수정·동일 파일 교체는 수행하지 않고 기존 파일과 새 결과를 구분한다.

## 완성본 저장

한글 검증 보고서가 가리키는 파일과 PDF를 확인하고 재저장본 내용 대조·전 페이지 검토를 실제로 끝낸 뒤에만 검토 완료를 기록하여 완성본 저장 도구를 실행한다. 명령행의 `--reviewed` 자체가 검토를 대신하지 않는다. 검증 보고서·파일·PDF가 바뀌면 저장을 중단하고 다시 확인한다.

같은 문서 교체는 연결된 대상과 기대 해시를 사용하고, 원본 양식은 교체 대상으로 삼지 않는다. 실패하면 이전 완성본과 검증된 후보를 보존하고 남은 단계를 알린다. 도구의 원본 보호를 해제하거나 원본을 먼저 삭제하지 않는다. 별도 버전 보관을 요청받으면 새 완성본 경로를 사용한다.

최종 응답은 완성본 경로, 구조 대조 결과, 한글 변환 결과, 전 페이지 검토 여부와 남은 미확정 항목을 구분한다. 한글 미설치·보호·잠금·접근 거절 등으로 확인하지 못한 단계는 검증 대기로 표시한다. 요청받지 않은 검사 이미지·임시 사본은 정리하고 완성본과 사용자 요청 결과만 남긴다.
