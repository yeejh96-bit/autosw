# autosw 처음 설정

- 이 스킬의 위치에서 두 단계 위가 설치된 플러그인 루트다. 그곳의 `scripts/install.ps1`을 Windows PowerShell에서 실행한다. 기본 위치는 Windows 바탕화면의 `autosw-workspace`다. 사용자가 기존 업무 폴더나 다른 위치를 지정했으면 `-Workspace`에 전체 경로를 전달한다.
- 설치는 지원 버전의 Node를 확인하고 없으면 Windows x64 전용 Node를 공식 배포에서 내려받는다. 실행 환경은 사용자 계정의 autosw 전용 위치에, 고정된 라이브러리는 플러그인에 준비한다. 기존 개인 폴더나 장부는 그대로 사용한다. 외부 다운로드나 로컬 실행 확인이 필요한 경우 앱의 안내를 따른다.
- 설치 결과의 업무 폴더 전체 경로와 준비 상태를 알린다. 해당 폴더를 Codex 프로젝트로 열고 새 대화에서 사용하도록 안내한다. 진단 성공과 실제 한글파일 출력 검증은 구분한다.
